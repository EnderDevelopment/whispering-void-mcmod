# Whispering Void

Whispering Void is a psychological horror Minecraft mod for NeoForge 1.21.1, featuring a mysterious entity that spawns rarely and unpredictably. Before day 10, the entity barely manifests, occasionally writing short mysterious phrases in chat. From day 10 onward, it engages more frequently and shows physical activity. The entity can "talk" in chat, selecting random phrases from pre-written pools divided into categories like observation, threat, question, and memory of player actions. It has 3 basic attacks and 5 abilities, with weighted random selection and multiple animation variants for each ability. All parameters are configurable for easy balancing.

## Install

1. Download the mod JAR file from the GitHub releases page.
2. Place the JAR file in the `mods` folder of your Minecraft instance.
3. Launch Minecraft with the NeoForge 1.21.1 profile.

## Use

1. Start a new world or load an existing one.
2. The Whispering Void entity will spawn rarely and unpredictably.
3. Interact with the entity by observing its behavior and reading its chat messages.
4. Use the config file to adjust spawn rates, health, damage, and abilities.
